# x86 Monitor 0.3 UI 优化

延续现有 Windows 95/2000 管理控制台风格，重点优化可读性、布局和交互。
用户已要求自主推进并明确 UI 为重点，不另行等待设计确认。

1. 固定本地构建依赖，建立可在 Windows 执行的 UI 回归测试。
2. 首页：桌面标题、范围汇总、清晰的工具栏、最小宽度适配的卡片；移除卡片重复名称，增加分组、备注、到期提示。移动端工具栏分行，触控目标放大。
3. 图表：边缘留白、纵轴/时间标签、区分空历史与加载/错误，详情时间范围依据 history_days。
4. 交互：实时更新保持焦点与选择区间；弹窗焦点限制、关闭后恢复；访客偏好安全保存；离线/等待/异常明确区分。
5. 演示单独入口与压力场景，生产安装包不包含演示数据。完成桌面、手机、详情截图。
6. 验证类型、单元测试、真实浏览器布局与交互、安装包哈希与根目录。独立本地 Git 仓库记录源码。实际 Hub 安装需可访问的测试实例；不虚报验证。
