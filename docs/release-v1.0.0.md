# Monitor Classic v1.0.0

Monitor Hub 中文复古主题的首个正式版本。名称 **Monitor Classic（经典监控台）**，短名 `monitor-classic`。

- Windows 95/2000 风格、桌面三列、手机布局和可折叠节点导航。
- CPU、内存、硬盘、流量进度及剩余额度，独立节点详情。
- 三网探测统一时间轴和毫秒刻度，显示延迟及丢包率。
- 文本/gzip 实时更新、轮询兜底、断线重连、历史异常重试。
- 安全文本渲染，明确区分离线/首次上报/异常指标，生产包隔离演示数据。

## 安装

Hub 后台「主题」→「从 GitHub 安装」填写 `https://github.com/ayingQAQ/monitor-theme-classic`，或上传附件 `theme.tar.gz`。

`theme.tar.gz.sha256` 用于 SHA-256 校验。GitHub 自动生成的 Source code ZIP/tar.gz 是源码，不是可安装主题包。

开发阶段的 `x86-monitor` 使用不同短名，请安装新的 `monitor-classic`。

预览图为 1920×1200（16:10），使用演示数据。源码以 MIT 许可证发布。
